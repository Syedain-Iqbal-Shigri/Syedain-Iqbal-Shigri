## 🏔️ Featured Project – Karakoram Tours

A **production‑ready tour booking platform** built with **Laravel 12**, **Tailwind CSS**, and **Stripe**.  
➡️ **[Live Demo](https://karakoram-tours.great-site.net)**  
➡️ **[GitHub Repo](https://github.com/Syedain-Iqbal-Shigri/Ecommerce-Tour-Booking-Taravel)**

<p align="center">
  <img src="https://via.placeholder.com/800x400?text=Add+Screenshot+Here" alt="Karakoram Tours Homepage" width="600"/>
</p>

**Tech used:** Laravel, PHP 8.3, MySQL, Tailwind CSS, Alpine.js, Stripe, InfinityFree, Git.

- ✅ Tour listings with filters (destination, difficulty, price)  
- ✅ Detailed tour pages with itineraries and highlights  
- ✅ User authentication (register/login)  
- ✅ Dynamic destination cards with live tour counts  
- ✅ Stripe payments ready to go live  
- ✅ SEO‑optimized and fully responsive  

### 🧠 Lessons Learned from Karakoram Tours
- Configured Laravel on shared hosting with PHP 8.3 and overcame Composer platform conflicts.
- Implemented a custom route to serve images from storage (since symbolic links are unsupported).
- Optimised database queries for dynamic destination counts.
- Integrated a responsive, mobile‑first UI with Tailwind CSS and Alpine.js.

- Caching at CDN & API levels, optimised DB queries & pagination
